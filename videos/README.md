# Видеообращения

Положите в эту папку до трёх MP4-видео и назовите их:

- `celebrity-1.mp4`
- `celebrity-2.mp4`
- `celebrity-3.mp4`

Карточки уже подключены в `index.html`. Видео запускаются только после нажатия пользователем на стандартную кнопку Play и воспроизводятся со звуком: атрибут `muted` намеренно не используется.

Чтобы добавить больше видео, скопируйте один блок `<article class="video-card reveal">...</article>` в контейнере `.video-row`, измените номер и путь к файлу. Горизонтальная лента поддерживает любое количество карточек, хотя текущий дизайн рассчитан прежде всего на три.
