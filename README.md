# Сайт для Алёны

Это полностью статический сайт: для его просмотра не нужен backend, Node.js или npm.

## Как открыть сайт на своём компьютере

1. Скачайте папку проекта целиком.
2. Убедитесь, что `index.html`, `styles.css` и `script.js` лежат рядом в одной папке.
3. Откройте `index.html` двойным щелчком — сайт запустится прямо в браузере.

Адрес `127.0.0.1` всегда обозначает **тот компьютер, на котором запущен локальный сервер**. Сервер, запущенный в среде разработки, недоступен с другого компьютера, поэтому ссылка вида `http://127.0.0.1:4173` не является публичной ссылкой на сайт.

## Необязательный локальный сервер

Если Python установлен на вашем компьютере, в папке проекта можно выполнить:

```bash
python3 -m http.server 4173
```

После этого на **том же компьютере** откройте <http://127.0.0.1:4173>.

## Публичная публикация

Чтобы получить ссылку, доступную с телефона или другого компьютера, папку проекта нужно разместить на статическом хостинге. Например, в Netlify Drop следует перетащить папку, в корне которой находится `index.html`. После загрузки Netlify выдаст публичный HTTPS-адрес.

Пока сайт находится в разработке. Итоговый ZIP-архив для Netlify Drop будет подготовлен после завершения всех правок по отдельной команде.
